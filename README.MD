# 🛒 E-Commerce App

A simple e-commerce web application that allows users to browse products, manage a shopping cart, and place orders. This project demonstrates the core features of a modern online shopping platform.

---

## Features

### Customer

- Browse products
- Search products
- Filter products by category
- View product details
- Add products to cart
- Update cart quantity
- Remove products from cart
- Checkout and place orders
- View order history

### Seller

- Add new products
- Edit existing products
- Delete products
- Manage inventory
- View customer orders

---

## Tech Stack

### Frontend

- Next.js
- TypeScript
- Tailwind CSS

### Backend

- Node.js with TypeScript
- Express.js

### Database

- MongoDB

### Other Tools

- JWT Authentication
- REST API

---

# Application Flow

```text
Login page (if not logged in)
  │
  ▼
Don't have account? go to register page from the link below.
  │
  ▼
After registration you'll be redirect to login page to login.
  │
  ▼
Home Page (according to logged in user role)
```
